# Tokens

No improvisar paleta. Variables en `app/globals.css`.

## Institucional

| Token | Hex | Uso |
|---|---|---|
| `--bg` | `#f9f9f9` | Fondo de página |
| `--bg-soft` | `#eef0ef` | Secciones suaves |
| `--bg-deep` / footer | `#3a3a3a` | Footer, textos fuertes |
| `--fg` | `#3a3a3a` | Texto |
| `--fg-muted` | `#727376` | Secundario |
| `--accent` | `#4caf50` | Barra del header, enlaces actuales, foco |
| `--brand-red` | `#e30613` | Kicker / acento de slogan |
| `--brand-navy` | `#1e2a4a` | Titulares |

Ford Antenna: 300, 400, 500, 600, 700, 900. Variable `--font-antenna`.
